# 09. 해커톤 당일 전환 체크리스트

> D-Day | 소요 시간: 약 10분 | 선행 조건: Phase 0~7 모두 완료

해커톤 당일, Groq → AWS Bedrock으로 전환할 때 아래 항목을 순서대로 확인한다.

---

## 전환 절차

| # | 작업 | 명령/조치 | 소요 시간 |
|---|------|----------|-----------|
| 1 | AWS credentials 확인 | `aws sts get-caller-identity` | 즉시 |
| 2 | `.env` 수정 | `MODEL_PROVIDER=groq` → `MODEL_PROVIDER=bedrock` | 즉시 |
| 3 | AWS credentials 입력 | `.env`에 `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` 입력 | 즉시 |
| 4 | Bedrock 모델 액세스 확인 | 콘솔에서 Claude 3.5 Sonnet v2 사용 가능 확인 | 1분 |
| 5 | DynamoDB 테이블 확인 | `aws dynamodb list-tables` → 4개 테이블 Active | 즉시 |
| 6 | S3 버킷 확인 | `aws s3 ls s3://cas-contracts-{팀명}/` | 즉시 |
| 7 | KB 상태 확인 | Bedrock 콘솔 → KB 상태 = Ready/Available | 1분 |
| 8 | CORS AllowedOrigins 갱신 | 당일 프론트엔드 URL 추가 (필요시) | 1분 |
| 9 | 통합 테스트 | DOCX 업로드 → 분석 → 리포트 확인 | 5분 |

## 빠른 검증 스크립트

```bash
#!/bin/bash
# scripts/verify-aws.sh

echo "=== 1. AWS Identity ==="
aws sts get-caller-identity --region ap-northeast-2

echo ""
echo "=== 2. DynamoDB Tables ==="
aws dynamodb list-tables --region ap-northeast-2

echo ""
echo "=== 3. S3 Bucket ==="
aws s3 ls s3://cas-contracts-{팀명}/ --region ap-northeast-2

echo ""
echo "=== 4. Bedrock Model Access ==="
aws bedrock get-foundation-model-availability \
  --model-id anthropic.claude-3-5-sonnet-20241022-v2:0 \
  --region ap-northeast-2

echo ""
echo "=== 5. Bedrock KB Status ==="
aws bedrock-agent get-knowledge-base \
  --knowledge-base-id {KB_ID} \
  --region ap-northeast-2 \
  --query 'knowledgeBase.status'

echo ""
echo "=== All checks complete ==="
```

## 긴급 대응

| 문제 | 원인 | 해결 |
|------|------|------|
| `AccessDeniedException` (Bedrock) | FTU 양식 미제출 또는 IAM 권한 부족 | [05. Bedrock 모델 액세스](05.bedrock-model-access.md) §5-2 양식 제출 + IAM 정책 확인 |
| `ResourceNotFoundException` (DynamoDB) | 테이블 미생성 또는 리전 불일치 | [04. DynamoDB](04.dynamodb.md) §4-3 CLI 명령 실행 + 리전 확인 |
| `NoSuchBucket` (S3) | 버킷 미생성 또는 이름 오류 | [03. S3 버킷](03.s3-bucket.md) §3-1 버킷 생성 + `.env` 이름 확인 |
| KB Sync 실패 | S3 권한 부족 | [03. S3 버킷](03.s3-bucket.md) §3-4 버킷 정책 수동 추가 |
| Groq Rate Limit | 무료 티어 한도 초과 | 잠시 대기 후 재시도 (분당 30 RPM) |
| OpenSearch Serverless 미생성 | KB 생성 직후 (15~30분 필요) | 사전에 미리 생성해둘 것 |

## 비용 모니터링

해커톤 예산: 약 25만원 (AWS 크레딧)

| 서비스 | 예상 비용 | 비고 |
|--------|-----------|------|
| Bedrock Claude 3.5 Sonnet v2 | ~$1~2 | 입출력 토큰 기준 |
| Bedrock Titan Embeddings | ~$0.1 | KB 인덱싱 시 |
| OpenSearch Serverless | ~$3~5/시간 | OCU 2개 기준 (검색+인덱싱) |
| DynamoDB On-Demand | ~$0.01 | 소량 요청 |
| S3 | ~$0.01 | 소량 저장 |

> **주의**: OpenSearch Serverless가 비용의 대부분을 차지한다. 해커톤 종료 후 반드시 KB 및 OpenSearch 컬렉션을 삭제할 것.

## 해커톤 종료 후 정리

```bash
# 1. Bedrock KB 삭제 (콘솔에서)
# Bedrock → Knowledge bases → cas-knowledge-base → Delete

# 2. OpenSearch Serverless 컬렉션 삭제 (콘솔에서)
# OpenSearch → Serverless → Collections → 삭제

# 3. DynamoDB 테이블 삭제
aws dynamodb delete-table --table-name cas-contracts --region ap-northeast-2
aws dynamodb delete-table --table-name cas-risk-reports --region ap-northeast-2
aws dynamodb delete-table --table-name cas-workflow-steps --region ap-northeast-2
aws dynamodb delete-table --table-name cas-prompt-templates --region ap-northeast-2

# 4. S3 버킷 비우기 + 삭제
aws s3 rm s3://cas-contracts-{팀명} --recursive --region ap-northeast-2
aws s3 rb s3://cas-contracts-{팀명} --region ap-northeast-2

# 5. IAM 사용자 삭제 (필요시)
```
