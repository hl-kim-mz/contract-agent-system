# 03. S3 버킷 생성 & 설정

> Phase 2 | 소요 시간: 약 10분 | 선행 조건: [02. AWS IAM](02.aws-iam.md)
> 참고: [AWS S3 공식 문서 — Creating a general purpose bucket](https://docs.aws.amazon.com/AmazonS3/latest/userguide/create-bucket-overview.html)

---

## 3-1. S3 버킷 생성

1. AWS 콘솔 → 상단 검색바에 `S3` 입력 → **S3** 서비스 클릭
2. 리전 확인 → **아시아 태평양 (서울) ap-northeast-2** 선택
3. 좌측 메뉴 **범용 버킷(General purpose buckets)** 클릭
4. **버킷 만들기(Create bucket)** 버튼 클릭

**버킷 만들기 페이지 설정:**

| 항목 | 값 | 비고 |
|------|-----|------|
| **버킷 이름(Bucket name)** | `cas-contracts-{팀명}` | 전 세계 고유, 소문자/숫자/하이픈만 |
| **AWS 리전** | 아시아 태평양 (서울) ap-northeast-2 | |
| **객체 소유권** | ACL 비활성화됨 (기본값) | |
| **퍼블릭 액세스 차단** | 모든 퍼블릭 액세스 차단 (기본값) | 4개 체크박스 유지 |
| **버킷 버전 관리** | 비활성화 (기본값) | |
| **기본 암호화** | SSE-S3 (기본값) | |

5. **버킷 만들기(Create bucket)** 클릭

## 3-2. 버킷 파일 구조

업로드 시 자동으로 경로가 생성되므로 사전 폴더 생성 불필요.

```
cas-contracts-{팀명}/
  {customer_name}/{contract_id}/v{version}.docx    ← 원본 DOCX
  {customer_name}/{contract_id}/v{version}.json    ← 파싱 결과 (KB 인덱싱 대상)
```

## 3-3. CORS 설정 (선택사항)

> Streamlit은 서버사이드 렌더링이므로 브라우저→S3 직접 업로드가 없다. 파일 업로드는 Python 백엔드(boto3)를 통해 처리되므로 **CORS 설정은 대부분 불필요**하다.

만약 Presigned URL 등 브라우저 직접 접근이 필요한 경우에만 설정:

1. S3 콘솔 → 버킷 → **권한(Permissions)** 탭
2. **교차 오리진 리소스 공유(CORS)** → **편집(Edit)**
3. 아래 JSON 붙여넣기:

```json
[
  {
    "AllowedHeaders": ["*"],
    "AllowedMethods": ["GET", "PUT", "POST"],
    "AllowedOrigins": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

## 3-4. Bedrock KB용 버킷 정책 (Phase 5 이후)

Bedrock Knowledge Base가 S3에 접근하려면 버킷 정책이 필요하다.
KB 생성 시 **콘솔에서 IAM 역할을 자동 생성**하면 별도 수동 설정 불필요.

수동 설정이 필요한 경우:

1. S3 콘솔 → 버킷 → **권한** → **버킷 정책** → **편집**
2. 아래 정책 붙여넣기 (ARN을 실제 값으로 교체):

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "BedrockKBAccess",
      "Effect": "Allow",
      "Principal": { "Service": "bedrock.amazonaws.com" },
      "Action": ["s3:GetObject", "s3:ListBucket"],
      "Resource": [
        "arn:aws:s3:::cas-contracts-{팀명}",
        "arn:aws:s3:::cas-contracts-{팀명}/*"
      ],
      "Condition": {
        "StringEquals": { "aws:SourceAccount": "{AWS_ACCOUNT_ID}" }
      }
    }
  ]
}
```
