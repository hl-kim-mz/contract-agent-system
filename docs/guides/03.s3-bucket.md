# 03. S3 버킷 생성 & 설정

> Phase 2 | 소요 시간: 약 10분 | 선행 조건: [02. AWS IAM](02.aws-iam.md)
> 참고: [AWS S3 공식 문서 — Creating a general purpose bucket](https://docs.aws.amazon.com/AmazonS3/latest/userguide/create-bucket-overview.html)

---

## 3-1. S3 버킷 생성

1. AWS 콘솔 → 상단 검색바에 `S3` 입력 → **S3** 서비스 클릭
2. 상단 네비게이션 바에서 리전 확인 → **아시아 태평양 (서울) ap-northeast-2** 선택
3. 좌측 메뉴 **범용 버킷(General purpose buckets)** 클릭
4. **버킷 만들기(Create bucket)** 버튼 클릭

**버킷 만들기 페이지 설정:**

| 항목 | 값 | 비고 |
|------|-----|------|
| **버킷 이름(Bucket name)** | `cas-contracts-{팀명}` | 전 세계 고유해야 함, 소문자/숫자/하이픈만 |
| **AWS 리전** | 아시아 태평양 (서울) ap-northeast-2 | 자동 선택되어 있음 |
| **객체 소유권(Object Ownership)** | ACL 비활성화됨 (기본값) | 기본값 유지 |
| **이 버킷의 퍼블릭 액세스 차단 설정** | 모든 퍼블릭 액세스 차단 (기본값) | 4개 체크박스 모두 활성화 유지 |
| **버킷 버전 관리(Bucket Versioning)** | 비활성화 (기본값) | 기본값 유지 |
| **기본 암호화(Default encryption)** | SSE-S3 (기본값) | 기본값 유지 |

5. **버킷 만들기(Create bucket)** 버튼 클릭

## 3-2. 버킷 폴더 구조

S3는 실제 폴더 개념이 없지만, 콘솔에서 prefix로 폴더를 만들 수 있다.
데이터 업로드 시 자동으로 경로가 생성되므로 **이 단계는 건너뛰어도 무방**.

업로드 시 다음 경로 구조를 따른다:
```
{customer_name}/{contract_id}/v{version}.docx    ← 원본 DOCX
{customer_name}/{contract_id}/v{version}.json    ← 파싱 결과 (KB 인덱싱 대상)
```

## 3-3. CORS 설정 (프론트엔드 업로드용)

> 참고: [AWS S3 CORS 설정 문서](https://docs.aws.amazon.com/AmazonS3/latest/userguide/enabling-cors-examples.html)

FE(Next.js)에서 Presigned URL로 직접 S3에 업로드하려면 CORS 설정이 필요하다.

1. S3 콘솔 → 생성한 버킷 이름 클릭
2. **권한(Permissions)** 탭 클릭
3. 아래로 스크롤 → **교차 오리진 리소스 공유(CORS)** 섹션 → **편집(Edit)** 클릭
4. 아래 JSON을 **CORS 구성 편집기**에 붙여넣기:

```json
[
  {
    "AllowedHeaders": ["*"],
    "AllowedMethods": ["GET", "PUT", "POST"],
    "AllowedOrigins": ["http://localhost:3000", "http://localhost:3001"],
    "ExposeHeaders": ["ETag", "x-amz-request-id"],
    "MaxAgeSeconds": 3600
  }
]
```

> **해커톤 당일**: `AllowedOrigins`에 실제 프론트엔드 URL을 추가하거나 `"*"`로 변경

5. **변경 사항 저장(Save changes)** 클릭

## 3-4. Bedrock KB용 버킷 정책 (Phase 5 이후 설정)

Bedrock Knowledge Base가 S3 버킷에 접근하려면 버킷 정책이 필요하다.
이 설정은 **Phase 5에서 KB를 생성할 때 자동으로 적용**되므로 (콘솔에서 IAM 역할을 자동 생성하도록 선택 시) 별도 수동 설정이 불필요하다.

만약 수동으로 설정해야 하는 경우:

1. S3 콘솔 → 버킷 → **권한(Permissions)** 탭
2. **버킷 정책(Bucket policy)** 섹션 → **편집(Edit)** 클릭
3. 아래 정책 붙여넣기 (ARN을 실제 값으로 교체):

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "BedrockKBAccess",
      "Effect": "Allow",
      "Principal": {
        "Service": "bedrock.amazonaws.com"
      },
      "Action": [
        "s3:GetObject",
        "s3:ListBucket"
      ],
      "Resource": [
        "arn:aws:s3:::cas-contracts-{팀명}",
        "arn:aws:s3:::cas-contracts-{팀명}/*"
      ],
      "Condition": {
        "StringEquals": {
          "aws:SourceAccount": "{AWS_ACCOUNT_ID}"
        }
      }
    }
  ]
}
```

4. **변경 사항 저장(Save changes)** 클릭
