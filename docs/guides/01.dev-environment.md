## 1-3. Groq API Key 발급 (사전 개발용)

사전 개발 단계에서는 Groq의 무료 API를 사용한다 (Llama 3.3 70B).

1. https://console.groq.com 접속
2. **Sign Up** 클릭 → Google/GitHub 계정으로 가입
3. 로그인 후 좌측 메뉴 **API Keys** 클릭
4. **Create API Key** 버튼 클릭
5. Key 이름 입력 (예: `cas-dev`) → **Submit** 클릭
6. 생성된 API Key 복사 → `.env` 파일에 저장

**Groq 무료 티어 제한사항:**
- 분당 30 요청 (RPM)
- 일 14,400 요청 (RPD)
- 분당 6,000 토큰 생성
- Llama 3.3 70B Versatile 모델 사용 가능

## 1-5. 모델 스위칭 코드 검증

```python
# 로컬에서 Groq 연동 테스트
import os
from strands import Agent
from strands.models.litellm import LiteLLMModel

model = LiteLLMModel(
    client_args={"api_key": os.getenv("GROQ_API_KEY")},
    model_id="groq/llama-3.3-70b-versatile",
    params={"max_tokens": 2048, "temperature": 0.3}
)

agent = Agent(model=model)
response = agent("안녕하세요, 테스트입니다.")
print(response)
```

이 코드가 정상 동작하면 사전 개발 환경 준비 완료.
