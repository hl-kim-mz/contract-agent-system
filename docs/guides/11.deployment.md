## 11-1. Docker Compose 구성

```yaml
# docker-compose.yml
version: "3.8"

services:
  app:
    build: .
    ports:
      - "8501:8501"     # Streamlit
      - "8000:8000"     # FastAPI
    volumes:
      - ./data:/app/data    # MCP compliance.db
    env_file:
      - .env
    environment:
      - MODEL_PROVIDER=bedrock
    restart: unless-stopped
```

```dockerfile
# Dockerfile
FROM python:3.11-slim

# Node.js (MCP 서버용)
RUN apt-get update && apt-get install -y curl sqlite3 && \
    curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && \
    apt-get install -y nodejs && \
    rm -rf /var/lib/apt/lists/*

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

# MCP 컴플라이언스 DB 초기화
RUN mkdir -p data && \
    sqlite3 data/compliance.db < scripts/init_compliance.sql && \
    sqlite3 data/compliance.db < scripts/seed_compliance.sql

EXPOSE 8501 8000

CMD ["sh", "-c", "uvicorn main:app --host 0.0.0.0 --port 8000 & streamlit run frontend/app.py --server.port 8501 --server.address 0.0.0.0"]
```

> DynamoDB/S3는 AWS 관리형이므로 Docker 내 초기화 불필요. MCP용 compliance.db만 로컬 초기화.

## 11-2. EC2 인스턴스 생성

| 항목 | 값 |
|------|-----|
| **인스턴스 유형** | `t3.medium` (2 vCPU, 4GB RAM) |
| **AMI** | Amazon Linux 2023 |
| **스토리지** | 20GB gp3 |
| **보안 그룹** | 인바운드: 8501(Streamlit), 8000(API), 22(SSH) |
| **IAM 역할** | EC2 인스턴스 프로파일 (Bedrock + S3 + DynamoDB 권한) |

```bash
# EC2 접속 후 Docker 설치
sudo yum update -y
sudo yum install -y docker git
sudo systemctl start docker && sudo systemctl enable docker
sudo usermod -aG docker ec2-user

# Docker Compose 설치
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose
```

## 11-3. 배포 실행

```bash
git clone {REPO_URL} && cd contract-agent-system

# .env 설정 (EC2 IAM 역할 사용 시 AWS credentials 불필요)
cp .env.example .env
# MODEL_PROVIDER=bedrock 확인

docker-compose up -d --build
docker-compose logs -f

# 접속 테스트
curl http://localhost:8501
```

접속 URL: `http://{EC2_PUBLIC_IP}:8501`
