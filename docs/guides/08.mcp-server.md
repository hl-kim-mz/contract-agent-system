## 8-1. mcp-server-sqlite 개요

사내 컴플라이언스 규정 DB를 MCP(Model Context Protocol)를 통해 Orchestrator Agent에 노출한다. `mcp-server-sqlite`는 오픈소스 MCP 서버로, SQLite DB에 대한 자율 쿼리 생성·실행을 지원한다.

> **MCP 컴플라이언스 DB (SQLite)** 는 메인 데이터 저장소(DynamoDB)와는 별개이다. 사내 규정 Mock 데이터만 담는 경량 DB로, MCP 프로토콜 표준을 준수한다. 실운영 시 사내 컴플라이언스 DB로 커넥터만 교체하면 된다.

## 8-3. 컴플라이언스 규정 DB 스키마 (compliance.db)

```sql
-- scripts/init_compliance.sql

CREATE TABLE IF NOT EXISTS compliance_rules (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    rule_code TEXT NOT NULL UNIQUE,
    category TEXT NOT NULL,        -- 배상 | 지재권 | 해지 | 지체상금 | 비밀유지 | 분쟁관할 | CR절차
    title TEXT NOT NULL,
    description TEXT NOT NULL,
    threshold TEXT,                -- 기준값 (예: "계약금액 100%", "0.05%/일")
    severity TEXT NOT NULL,        -- HIGH | MEDIUM | LOW
    department TEXT,               -- 소관 부서
    updated_at TEXT NOT NULL
);
```

## 8-5. Strands SDK에서 MCP 연동

```python
from strands import Agent
from strands.tools.mcp import MCPClient
from mcp import StdioServerParameters

mcp_client = MCPClient(
    lambda: StdioServerParameters(
        command="npx",
        args=["-y", "@anthropic/mcp-server-sqlite", "--db-path", "data/compliance.db"]
    )
)

# Orchestrator에서 MCP 도구를 포함하여 Agent 생성
with mcp_client:
    orchestrator = Agent(
        model=sonnet,
        tools=[
            parsing_agent.as_tool(),
            risk_agent.as_tool(),
            search_agent.as_tool(),
            *mcp_client.list_tools()    # MCP 도구 자동 등록
        ]
    )
```

> Orchestrator가 "사내 규정 확인해줘" 질의를 받으면, MCP 클라이언트가 자율적으로 SQL 쿼리를 생성·실행한다.
