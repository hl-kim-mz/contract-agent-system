# 05. Bedrock 모델 액세스 신청

> Phase 4 | 소요 시간: 약 5분 | 선행 조건: [02. AWS IAM](02.aws-iam.md)
> 참고: [AWS Bedrock Model Access 공식 문서](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access.html)
> **모델**: Orchestrator/RiskAgent = Claude Sonnet 4 | ParsingAgent/SearchAgent = Claude Haiku 4

---

## 5-1. 모델 액세스 정책 (2025년 이후 변경사항)

**2025년 이후 AWS Bedrock은 기본적으로 모든 모델에 대한 액세스가 활성화되어 있다.**
다만, Anthropic 모델의 경우 **최초 1회 사용 사례 양식(FTU Form)** 제출이 필요하다.

필요한 IAM 권한:
- `aws-marketplace:Subscribe`
- `aws-marketplace:Unsubscribe`
- `aws-marketplace:ViewSubscriptions`

> Phase 1에서 `AmazonBedrockFullAccess` 정책을 연결했다면 이미 포함되어 있다.

## 5-2. Anthropic 모델 최초 사용 양식 제출

1. AWS 콘솔 → 상단 검색바에 `Bedrock` 입력 → **Amazon Bedrock** 클릭
2. 리전 확인: **아시아 태평양 (서울) ap-northeast-2**
3. 좌측 메뉴 **모델 카탈로그(Model catalog)** 또는 **Foundation models**
4. Anthropic 섹션에서 **Claude Sonnet 4** 클릭 (Haiku 4도 동일하게 확인)
5. 최초 접속 시 **사용 사례 세부 정보 제출(Submit use case details)** 양식이 표시됨
6. 양식 작성:

| 필드 | 입력값 |
|------|--------|
| Company name | 메가존클라우드 (또는 팀명) |
| Company website | https://megazone.com |
| Intended users | Internal (내부 사용) |
| Industry | Technology / Cloud Services |
| Use cases | Contract document risk analysis using AI agents for internal contract management system |

7. **Submit form** 클릭
8. 제출 후 **즉시 액세스 가능** (별도 승인 대기 없음)

> **주의**: 이 양식은 AWS 계정당 1회만 제출하면 된다. AWS Organization 내 다른 계정에도 상속된다.

## 5-3. Titan Embeddings V2 확인

Amazon 자체 모델(Titan)은 AWS Marketplace 제품이 아니므로 별도 양식 제출이 불필요하다.
즉시 사용 가능하다.

확인 방법:
1. Bedrock 콘솔 → **모델 카탈로그(Model catalog)**
2. Amazon 섹션 → **Titan Text Embeddings V2** 검색
3. 모델 상세에서 `model_id` 확인: `amazon.titan-embed-text-v2:0`

## 5-4. 모델 액세스 확인 (CLI)

```bash
# Anthropic Claude Sonnet 4 액세스 확인
aws bedrock get-foundation-model-availability \
  --model-id anthropic.claude-sonnet-4-20250514 \
  --region us-west-2

# Anthropic Claude Haiku 4 액세스 확인
aws bedrock get-foundation-model-availability \
  --model-id anthropic.claude-haiku-4-20250414 \
  --region us-west-2

# Titan Embeddings 확인
aws bedrock get-foundation-model-availability \
  --model-id amazon.titan-embed-text-v2:0 \
  --region us-west-2
```

## 5-5. 모델 테스트 (Bedrock Playground)

1. Bedrock 콘솔 → 좌측 **플레이그라운드(Playgrounds)** → **채팅(Chat)**
2. 모델 선택 드롭다운에서 **Anthropic** → **Claude Sonnet 4** 선택
3. 프롬프트 입력: `"안녕하세요, 계약서 분석 테스트입니다."` → **실행(Run)** 클릭
4. 정상 응답이 오면 모델 액세스 완료
