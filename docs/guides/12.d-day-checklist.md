## 빠른 검증 스크립트

```bash
#!/bin/bash
# scripts/verify-aws.sh

echo "=== 1. AWS Identity ==="
aws sts get-caller-identity --region ap-northeast-2

echo ""
echo "=== 2. DynamoDB Tables ==="
aws dynamodb list-tables --region ap-northeast-2

echo ""
echo "=== 3. S3 Bucket ==="
aws s3 ls s3://cas-contracts-{팀명}/ --region ap-northeast-2

echo ""
echo "=== 4. Bedrock Model Access ==="
aws bedrock get-foundation-model-availability \
  --model-id anthropic.claude-sonnet-4-20250514 \
  --region us-west-2

echo ""
echo "=== 5. Bedrock KB Status ==="
aws bedrock-agent get-knowledge-base \
  --knowledge-base-id {KB_ID} \
  --region us-west-2 \
  --query 'knowledgeBase.status'

echo ""
echo "=== 6. MCP Compliance DB ==="
sqlite3 data/compliance.db "SELECT COUNT(*) FROM compliance_rules;"

echo ""
echo "=== All checks complete ==="
```

## 긴급 대응

| 문제 | 원인 | 해결 |
|------|------|------|
| `AccessDeniedException` (Bedrock) | FTU 양식 미제출 / IAM 권한 부족 | [05](05.bedrock-model-access.md) 양식 제출 + IAM 확인 |
| `ResourceNotFoundException` (DynamoDB) | 테이블 미생성 / 리전 불일치 | [04](04.dynamodb.md) CLI 명령 실행 |
| `NoSuchBucket` (S3) | 버킷 미생성 / 이름 오류 | [03](03.s3-bucket.md) 버킷 생성 |
| KB Sync 실패 | S3 권한 부족 | [03](03.s3-bucket.md) §3-4 버킷 정책 추가 |
| Guardrails 미생성 | 콘솔 사전 작업 누락 | [07](07.bedrock-guardrails.md) §7-2 정책 생성 |
| MCP 서버 실행 실패 | Node.js 미설치 / compliance.db 없음 | [08](08.mcp-server.md) 확인 |
| Groq Rate Limit | 무료 티어 한도 초과 | 잠시 대기 후 재시도 |
| OpenSearch 미생성 | KB 생성 직후 (15~30분 필요) | 사전에 미리 생성 |

## 비용 모니터링

해커톤 예산: 약 25만원 (AWS 크레딧)

| 서비스 | 예상 비용 | 비고 |
|--------|-----------|------|
| Bedrock Claude Sonnet 4 | ~$1~2 | 입출력 토큰 |
| Bedrock Titan Embeddings | ~$0.1 | KB 인덱싱 |
| OpenSearch Serverless | ~$3~5/시간 | OCU 2개 (비용 최대) |
| DynamoDB On-Demand | ~$0.01 | 소량 요청 |
| S3 | ~$0.01 | 소량 저장 |

> **주의**: OpenSearch Serverless가 비용 대부분. 해커톤 종료 후 KB + OpenSearch 컬렉션 반드시 삭제.

## 해커톤 종료 후 정리

```bash
# 1. Bedrock KB 삭제 (콘솔)
# 2. OpenSearch Serverless 컬렉션 삭제 (콘솔)

# 3. DynamoDB 테이블 삭제
aws dynamodb delete-table --table-name cas-contracts --region ap-northeast-2
aws dynamodb delete-table --table-name cas-risk-reports --region ap-northeast-2
aws dynamodb delete-table --table-name cas-workflow-steps --region ap-northeast-2
aws dynamodb delete-table --table-name cas-prompt-templates --region ap-northeast-2

# 4. S3 버킷 비우기 + 삭제
aws s3 rm s3://cas-contracts-{팀명} --recursive
aws s3 rb s3://cas-contracts-{팀명}

# 5. IAM 사용자 삭제 (필요시)
# 6. EC2 인스턴스 종료
```
