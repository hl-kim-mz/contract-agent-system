# 02. AWS 계정 & IAM 세팅

> Phase 1 | 소요 시간: 약 15분 | 선행 조건: 없음

---

## 2-1. AWS 계정 생성 (이미 있으면 건너뛰기)

1. https://aws.amazon.com 접속
2. 우측 상단 **AWS 계정 생성** (Create an AWS Account) 클릭
3. 이메일, 비밀번호, 계정 이름 입력
4. 결제 수단 등록 (해커톤 예산 25만원 한도)
5. 본인 인증 완료

## 2-2. IAM 사용자 생성 (루트 계정 대신 사용)

> **주의**: Bedrock Knowledge Base는 루트 사용자로 생성 불가. 반드시 IAM 사용자 필요.

1. AWS 콘솔 로그인 → 상단 검색바에 `IAM` 입력 → **IAM** 서비스 클릭
2. 좌측 메뉴 **사용자(Users)** 클릭
3. **사용자 생성(Create user)** 버튼 클릭
4. 사용자 이름: `cas-admin` 입력
5. **AWS Management Console에 대한 사용자 액세스 권한 제공** 체크
6. **다음(Next)** 클릭

## 2-3. IAM 정책 연결

**권한 설정** 단계에서:

1. **직접 정책 연결(Attach policies directly)** 선택
2. 아래 관리형 정책을 검색하여 체크:

| 정책 이름 | 용도 |
|-----------|------|
| `AmazonBedrockFullAccess` | Bedrock 모델 호출, KB 생성/관리 |
| `AmazonS3FullAccess` | S3 버킷 생성, 파일 업로드/조회 |
| `AmazonDynamoDBFullAccess` | DynamoDB 테이블 생성/CRUD |
| `AmazonOpenSearchServiceFullAccess` | OpenSearch Serverless (KB 벡터 저장소) |

3. **다음(Next)** → **사용자 생성(Create user)** 클릭
4. 콘솔 로그인 URL, 사용자 이름, 비밀번호 메모

## 2-4. 프로그래밍 액세스용 Access Key 생성

1. IAM → **사용자(Users)** → `cas-admin` 클릭
2. **보안 자격 증명(Security credentials)** 탭 클릭
3. **액세스 키(Access keys)** 섹션 → **액세스 키 만들기(Create access key)** 클릭
4. 사용 사례: **Command Line Interface (CLI)** 선택
5. 확인 체크박스 체크 → **다음(Next)** → **액세스 키 만들기(Create access key)** 클릭
6. `Access Key ID`와 `Secret Access Key` 복사 → `.env`에 저장

```bash
# .env에 추가
AWS_ACCESS_KEY_ID=AKIA...
AWS_SECRET_ACCESS_KEY=xxxx...
```

## 2-5. AWS CLI 설정 (선택사항)

```bash
# AWS CLI가 설치되어 있다면
aws configure --profile megathon
# AWS Access Key ID: 위에서 복사한 값
# AWS Secret Access Key: 위에서 복사한 값
# Default region name: ap-northeast-2
# Default output format: json
```
