## 7-1. Mock 표준 계약서 DOCX 작성

데모를 위해 최소 3개의 Mock 계약서 DOCX를 준비한다.
Claude를 사용하여 MZC 형태의 Mock 계약서를 생성한다.

**필요한 파일:**

| 파일명 | 유형 | 목적 |
|--------|------|------|
| `A사_SI도급_v1.docx` | SI 도급 (비표준) | 첫 번째 업로드 — 리스크 탐지 데모 |
| `A사_SI도급_v2.docx` | SI 도급 (비표준, 수정) | Diff 데모 — v1 대비 변경 |
| `B사_NDA_v1.docx` | NDA (표준) | LOW 리스크 — 자체 승인 데모 |
| `C사_MSA_v1.docx` | MSA (비표준) | 검색(RAG) 히스토리 데모 |

**SI 도급 Mock 계약서(v1)에 반드시 포함할 리스크 조항:**
- 손해배상 조항: 배상한도 미설정 (→ HIGH: 무제한 배상책임)
- CR 절차: 변경요청 처리 기준 없음 (→ HIGH: CR 절차 미정의)
- 지체상금: 0.15%/일 (→ MEDIUM: MZC 기준 0.05% 초과)
- 계약금액: 15억원 (→ 재무팀 병렬 검토 트리거)

**v2에서 변경할 포인트 (Diff 시나리오):**
- 지체상금율 변경: 0.15% → 0.08% (개선되었으나 여전히 초과)
- 손해배상 한도 추가: "계약금액의 200% 이내" (여전히 HIGH)

## 7-3. prompt-templates 초기 데이터 시딩

```python
# scripts/seed_prompts.py
import boto3
import uuid
from datetime import datetime

dynamodb = boto3.resource('dynamodb', region_name='ap-northeast-2')
table = dynamodb.Table('cas-prompt-templates')

templates = [
    {
        "id": str(uuid.uuid4()),
        "contract_type": "SI",
        "prompt_name": "SI 도급 계약 리스크 분석",
        "system_prompt": """당신은 메가존클라우드(MZC)의 계약검토 전문가입니다.
아래 계약서 JSON을 분석하여 MZC 내부 기준에 따라 리스크를 탐지하세요.

[MZC 리스크 판단 기준]
1. 무제한 배상책임: 배상한도 미설정 또는 계약금액 초과 → HIGH
2. IP 완전이전: 개발 산출물 지재권 전부 이전 → HIGH
3. 일방적 해지권: 갑 단독 해지 + 위약금 없음 → HIGH
4. 과도한 지체상금: 0.1%/일 초과 → MEDIUM (기준: 0.05%/일)
5. 자동갱신 조건: 갱신 거절 기한 미명시 → MEDIUM
6. 분쟁 관할 불리: 상대방 소재지 법원 → MEDIUM
7. 비밀유지 기간 미정: 계약 종료 후 기간 없음 → LOW
8. 하자보수 기간 미달: 1년 미만 (SI 계약) → MEDIUM
9. CR 절차 미정의: 변경요청 처리 기준 없음 (SI) → HIGH

각 조항에 대해 risk_level, risk_type, reason, recommendation, financial_impact를 포함한 JSON을 반환하세요.""",
        "updated_at": datetime.utcnow().isoformat(),
        "updated_by": "system"
    },
    {
        "id": str(uuid.uuid4()),
        "contract_type": "NDA",
        "prompt_name": "NDA 계약 리스크 분석",
        "system_prompt": """당신은 메가존클라우드(MZC)의 계약검토 전문가입니다.
아래 NDA 계약서 JSON을 분석하여 리스크를 탐지하세요.

[NDA 리스크 판단 기준]
1. 비밀유지 기간: 계약 종료 후 3년 미만 → MEDIUM
2. 비밀정보 범위: 과도하게 넓은 범위 → MEDIUM
3. 분쟁 관할: 상대방 소재지 법원 → MEDIUM
4. 손해배상: 과도한 위약벌 → HIGH""",
        "updated_at": datetime.utcnow().isoformat(),
        "updated_by": "system"
    },
    {
        "id": str(uuid.uuid4()),
        "contract_type": "MSA",
        "prompt_name": "MSA 계약 리스크 분석",
        "system_prompt": """당신은 메가존클라우드(MZC)의 계약검토 전문가입니다.
아래 MSA 기본계약서 JSON을 분석하여 리스크를 탐지하세요.

[MSA 리스크 판단 기준]
1. 무제한 배상책임: 배상한도 미설정 → HIGH
2. 일방적 해지: 상대방만 해지 가능 → HIGH
3. 자동갱신: 거절 기한 미명시 → MEDIUM
4. 분쟁 관할: 상대방 소재지 법원 → MEDIUM
5. IP 귀속: 공동 소유 미명시 → MEDIUM""",
        "updated_at": datetime.utcnow().isoformat(),
        "updated_by": "system"
    }
]

for t in templates:
    table.put_item(Item=t)
```

## 7-4. RAG 검색용 KB 동기화

Mock 계약서를 파싱하여 JSON으로 변환한 뒤 S3에 업로드하고 KB를 동기화한다.

```bash
# 1. JSON 파일 업로드 (파싱 결과)
aws s3 cp samples/A사_SI도급_v1.json s3://cas-contracts-{팀명}/A사/contract-001/v1.json
aws s3 cp samples/B사_NDA_v1.json s3://cas-contracts-{팀명}/B사/contract-002/v1.json
aws s3 cp samples/C사_MSA_v1.json s3://cas-contracts-{팀명}/C사/contract-003/v1.json

# 2. KB 동기화 트리거
aws bedrock-agent start-ingestion-job \
  --knowledge-base-id {KB_ID} \
  --data-source-id {DATA_SOURCE_ID} \
  --region ap-northeast-2
```

## 7-5. 데모 시나리오 리허설 체크리스트

| # | 시나리오 단계 | 검증 항목 | 통과 |
|---|--------------|-----------|------|
| 1 | DOCX 업로드 | `/upload` 화면에서 드래그&드롭 → S3 저장 확인 | ☐ |
| 2 | 파싱 → Contract JSON | 조항 분리, 금액/날짜 추출 정상 확인 | ☐ |
| 3 | 리스크 분석 | HIGH 3건 탐지 (배상, CR, 지체상금) | ☐ |
| 4 | Diff 뷰 | v1→v2 변경사항 시각화 | ☐ |
| 5 | 워크플로우 라우팅 | 계약팀→법무팀→본부장 + 재무팀 병렬 | ☐ |
| 6 | Mock 승인 | 계약팀 의견 입력 + 승인 → 다음 단계 | ☐ |
| 7 | RAG 검색 | "과거 CR 조항 처리" 검색 → 결과 반환 | ☐ |
| 8 | 프롬프트 수정 | SI 프롬프트 편집 → 즉시 재분석 | ☐ |
