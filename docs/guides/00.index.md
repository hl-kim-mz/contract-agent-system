## 실행 순서 & 의존성 맵

```
시간 ──────────────────────────────────────────────────────────►

[Block A: 즉시 시작 — 병렬]
  ├─ 01. 개발 환경 ─────────────┐
  └─ 02. AWS 계정 & IAM ────────┤
                                │
[Block B: IAM 완료 후 — 병렬]   ▼
  ├─ 03. S3 버킷 ──────────────┐
  ├─ 04. DynamoDB ─────────────┤   ← 3개 병렬 가능
  └─ 05. Bedrock 모델 액세스 ──┤
                                │
[Block C: S3 + 모델 액세스 후]  ▼
  └─ 06. Bedrock KB ───────────┐   ← OpenSearch 15~30분 대기
                                │
[Block D: 전체 인프라 완료 후]  ▼
  ├─ 07. 데모 데이터 ──────────┐   ← 병렬 가능
  └─ 08. AI Agent 설계 ────────┤
                                │
[Block E: 해커톤 당일]          ▼
  └─ 09. 당일 전환 체크리스트
```

**의존성 요약:**

| 작업 | 선행 조건 | 비고 |
|------|-----------|------|
| 01. 개발 환경 | 없음 | 즉시 시작 |
| 02. AWS IAM | 없음 | 즉시 시작, 01과 병렬 |
| 03. S3 | 02 완료 | |
| 04. DynamoDB | 02 완료 | 03과 병렬 |
| 05. Bedrock 모델 | 02 완료 | 03, 04와 병렬 |
| 06. Bedrock KB | 03 + 05 완료 | **병목** — OpenSearch 프로비저닝 15~30분 |
| 07. 데모 데이터 | 03 + 04 + 06 완료 | |
| 08. AI Agent | 01 완료 (Groq 테스트 가능) | 07과 병렬, Bedrock은 당일 전환 |
| 09. 당일 체크리스트 | 전체 완료 | D-Day 실행 |

**크리티컬 패스:**
```
02. IAM → 03. S3 → 06. KB (15~30분 대기) → 07. 데모 데이터
```
총 최소 약 1시간 — KB의 OpenSearch 프로비저닝이 가장 긴 대기. **가장 먼저 착수해야 한다.**

## 인간 vs AI 역할 분담

### 반드시 인간이 해야 하는 작업

콘솔 로그인, 결제 수단 등록, 라이선스 동의 등 **인증/인가/법적 동의**가 필요한 작업.

| 작업 | 이유 | 소요 시간 | 가이드 |
|------|------|-----------|--------|
| AWS 계정 생성 & 결제 수단 등록 | 신용카드, 본인인증 필요 | 10분 | [02](02.aws-iam.md) §2-1 |
| Anthropic FTU 양식 제출 | 회사명, 용도 등 비즈니스 판단 필요 | 3분 | [05](05.bedrock-model-access.md) §5-2 |
| Bedrock Playground 모델 테스트 | 응답 품질 육안 확인 | 2분 | [05](05.bedrock-model-access.md) §5-5 |
| Mock 계약서 DOCX 내용 검수 | 도메인 전문성 — 리스크 조항이 MZC 기준에 부합하는지 | 15분 | [07](07.demo-data.md) §7-1 |
| 프롬프트 품질 판단 & 튜닝 방향 | 리스크 탐지 정확도 판단은 인간 전문가 영역 | 20분 | [08](08.ai-agent.md) §8-4 |
| 데모 리허설 & 시나리오 최종 확인 | 발표 흐름 판단 | 15분 | [07](07.demo-data.md) §7-5 |
| CORS AllowedOrigins 당일 갱신 | 당일 URL 확정 후 입력 | 1분 | [09](09.d-day-checklist.md) |

**인간 필수 총 공수: 약 1시간 10분** (대기 시간 제외)

## 작업별 상세 역할 분담

### Block A: 환경 준비 (0~20분)

| 작업 | 담당 | 구체적 행동 |
|------|------|------------|
| Python venv 생성 | AI | `python3 -m venv .venv && source .venv/bin/activate` |
| pip install | AI | 전체 의존성 설치 |
| Groq API Key 발급 | **인간** | 웹 가입 + Key 생성 (본인 인증) |
| `.env` 작성 | AI | 템플릿 생성, 인간이 시크릿 값만 입력 |
| AWS 계정 생성 | **인간** | 결제 수단 등록 필수 |
| IAM 사용자 + 정책 | AI 가능 | CLI 자동화 가능. 단, 루트 계정 Access Key가 먼저 필요 → **인간이 먼저 생성** |
| Access Key 생성 | **인간** | 콘솔에서 생성 → `.env`에 붙여넣기 |

### Block B: AWS 인프라 (20~30분)

| 작업 | 담당 | 구체적 행동 |
|------|------|------------|
| S3 버킷 생성 | AI | `aws s3api create-bucket` CLI |
| S3 CORS 설정 | AI | `aws s3api put-bucket-cors` CLI |
| DynamoDB 4개 테이블 | AI | `aws dynamodb create-table` CLI 4회 |
| Anthropic FTU 양식 | **인간** | 콘솔에서 양식 제출 (비즈니스 판단) |
| Titan Embeddings 확인 | AI | `aws bedrock get-foundation-model-availability` CLI |

### Block C: Knowledge Base (30~60분)

| 작업 | 담당 | 구체적 행동 |
|------|------|------------|
| KB 생성 (콘솔) | **인간** | "Quick create" OpenSearch Serverless는 콘솔에서만 가능 |
| KB 생성 대기 (15~30분) | — | OpenSearch Serverless 프로비저닝 대기 |
| KB ID 메모 → .env | **인간** | 콘솔에서 복사 |
| S3 버킷 정책 (자동) | 자동 | KB 생성 시 IAM 역할 자동 생성하면 불필요 |

> **왜 인간이 해야 하는가**: Bedrock KB의 "Quick create a new vector store"는 콘솔 전용 기능이다. API로 생성하려면 OpenSearch Serverless 컬렉션을 수동으로 먼저 만들어야 하므로 콘솔이 훨씬 빠르다.

### Block D: 데이터 & 코드 (60~90분)

| 작업 | 담당 | 구체적 행동 |
|------|------|------------|
| Mock DOCX 생성 (4개) | AI | python-docx로 자동 생성 |
| Mock DOCX 내용 검수 | **인간** | 리스크 조항이 의도대로 포함됐는지 확인 |
| 데모 데이터 S3 업로드 | AI | `aws s3 cp` CLI |
| prompt-templates 시딩 | AI | 시딩 스크립트 실행 |
| KB 동기화 트리거 | AI | `start_ingestion_job` API |
| 프롬프트 초안 작성 | AI | MZC 9개 리스크 기준 기반 |
| 프롬프트 품질 판단 | **인간** | 리스크 탐지 정확도 육안 확인 |
| FastAPI 백엔드 | AI | requirements.md + api-spec.md 기반 전체 구현 |
| Next.js 프론트엔드 | AI | requirements.md §4 화면 목록 기반 전체 구현 |
| Agent 코드 (Strands) | AI | agents/config.py, tools, agent 초기화 |
| DOCX 파서 코드 | AI | python-docx + regex |
| Rule Engine 코드 | AI | if/else 라우팅 |
| Diff 로직 코드 | AI | deepdiff |

### Block E: 당일 (D-Day)

| 작업 | 담당 | 구체적 행동 |
|------|------|------------|
| `.env` MODEL_PROVIDER 변경 | **인간** | `groq` → `bedrock` |
| AWS credentials 입력 | **인간** | 당일 제공받은 계정 정보 |

| 데모 리허설 | **인간** | 발표 흐름 최종 확인 |
