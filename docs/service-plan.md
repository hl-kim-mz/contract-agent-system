## 2. 문제 정의

> "지금 우리는 계약서를 받으면 어떻게 하고 있나요?"

메가존클라우드는 연간 수천 건의 계약서를 처리합니다.  
고객사마다 계약서 형태가 다르고, 검토 과정은 사람의 손과 눈에 의존하고 있습니다.

### 현장에서 반복되는 5가지 문제

**① 리스크를 놓치는 검토**  
영업팀 담당자가 직접 계약서를 검토하지만, 법무 전문가가 아니기 때문에 독소조항을 놓치는 경우가 발생합니다. 배상한도가 없거나, 지체상금율이 지나치게 높은 조항이 그대로 체결되기도 합니다.

**② 계약 체결까지 평균 수일 소요**  
계약서 검토는 계약팀 → 법무팀 → 본부장 순서로 진행되는데, 각 단계마다 이메일·메신저로 파일을 전달하고 담당자를 기다려야 합니다. 급한 계약도 며칠씩 걸립니다.

**③ 버전 관리의 혼란**  
`계약서_v2_최종_진짜최종.docx` — 누구나 한 번쯤 겪어본 상황입니다. 어떤 버전이 최신인지, 어디서 무엇이 바뀌었는지 파악하기 어렵습니다.

**④ 과거 계약 이력을 찾을 수 없음**  
"저번에 A사랑 계약할 때 배상 조항을 어떻게 했더라?" — 파일 탐색기를 뒤지거나 담당자에게 직접 물어봐야 합니다. 같은 실수가 반복됩니다.

**⑤ 검토 현황을 한눈에 볼 수 없음**  
계약이 지금 어느 단계에 있는지, 누가 검토 중인지 실시간으로 확인하기 어렵습니다.

## 3. 솔루션 — CAS가 해결하는 방법

> CAS는 **3개의 AI Agent**가 협력하여 계약 검토의 전 과정을 자동화합니다.

### AI Agent 3인의 역할

```
계약서 업로드
     │
     ▼
┌─────────────────────────────────────────┐
│  📄 문서 읽기 (AI 없이 코드로 처리)       │
│  계약서 Word 파일 → 조항별 구조 분석     │
└─────────────────┬───────────────────────┘
                  │
     ┌────────────┴────────────┐
     ▼                         ▼
┌──────────────┐       ┌──────────────────┐
│ 🔍 법률 검토  │       │ 📚 히스토리 검색  │
│    Agent     │       │     Agent        │
│              │       │                  │
│ MZC 기준으로 │       │ 과거 유사 계약을  │
│ 위험 조항    │       │ 자연어로 검색하고 │
│ 탐지 + 보고서│       │ 답변 제공        │
└──────┬───────┘       └──────────────────┘
       │
       ▼
┌──────────────────────────────────────────┐
│  ⚙️ 검토 라우팅 (규칙 기반 자동화)          │
│  리스크 수준에 따라 계약팀/법무팀/본부장에  │
│  자동으로 검토 요청 발송                  │
└──────────────────────────────────────────┘
```

#### 법률 검토 Agent — "위험 조항을 먼저 알려드립니다"

계약서의 각 조항을 MZC 내부 기준과 비교하여 위험도를 판단합니다.  
배상한도 미설정, 지체상금 과다, IP 완전 이전 등 9가지 유형의 위험을 자동 탐지하고  
수정 방향을 함께 제안합니다. 판단 기준은 담당자가 직접 수정할 수 있습니다.

#### 검색 Agent — "과거 계약에서 어떻게 했는지 바로 찾아드립니다"

"A사와의 과거 계약에서 배상 조항을 어떻게 처리했나요?" 같은 질문을 자연어로 입력하면  
전체 계약서 이력을 검색해 관련 내용과 출처를 함께 제공합니다.

#### 검토 라우팅 — "적합한 사람에게 자동으로 전달합니다"

AI가 판단한 위험 수준에 따라 검토 순서와 담당자를 자동으로 결정합니다.  
HIGH 위험: 계약팀 → 법무팀 → 본부장 (3단계) / 계약금액 10억 이상: 재무팀 병렬 검토 추가

## 4. 핵심 가치 제안

### ① 계약 체결 시간을 "수일 → 당일"로

지금까지 며칠씩 걸리던 계약 검토를 **3분 이내 AI 분석 + 자동 라우팅**으로 대폭 단축합니다.  
담당자가 이메일을 보내고 기다리는 시간을 없애고, 검토 현황을 실시간으로 확인할 수 있습니다.

### ② 법무 전문가가 없어도 위험 조항을 놓치지 않는다

영업팀 담당자도 계약서를 업로드하는 것만으로 **MZC 사내 기준에 맞춘 리스크 분석 결과**를 즉시 받아볼 수 있습니다. AI의 판단은 참고용이며, 최종 결정은 사람이 합니다.

### ③ 계약 지식이 조직 자산으로 쌓인다

모든 계약서와 검토 이력이 누적되어 언제든 자연어로 검색할 수 있습니다.  
담당자가 바뀌어도 과거 계약의 맥락을 그대로 활용할 수 있고, 같은 실수를 반복하지 않습니다.

## 5. 사용자 시나리오 — 영업팀 담당자 관점

> **상황**: 영업팀 김대리가 A사로부터 SI 도급 계약서를 받았습니다.  
> 계약 체결이 급하고, 법무팀에 요청하면 며칠은 걸릴 것 같습니다.

---

**Step 1. 계약서 업로드** *(30초)*

CAS 대시보드에 접속해 계약서 Word 파일을 드래그합니다.  
고객사명(A사)과 계약 유형(SI 도급)을 선택하고 업로드 버튼을 누릅니다.

---

**Step 2. AI 분석 결과 확인** *(3분 이내)*

분석이 완료되면 리스크 리포트가 자동으로 생성됩니다.

```
🔴 HIGH 위험  |  A사 SI 도급 계약서 v1

위험 조항 3건이 발견되었습니다.

❶ 무제한 배상책임
   배상 한도 조항이 없어 계약금액을 초과하는 손해배상이 청구될 수 있습니다.
   → 수정 제안: "배상책임은 계약금액의 100%를 한도로 한다" 조항 삽입 요청

❷ 변경요청(CR) 절차 미정의
   공사 범위 변경 시 비용 정산 기준이 없어 분쟁 가능성이 있습니다.

❸ 지체상금율 0.15%/일
   MZC 기준(0.05%/일)을 초과합니다.
```

---

**Step 3. 이전 버전과 비교** *(자동)*

지난번 A사 계약서(v1)와 이번 계약서(v2)의 차이점이 자동으로 표시됩니다.  
"지체상금율이 0.1%에서 0.15%로 높아졌습니다" 와 같이 변경 내용과 위험 영향을 한눈에 확인합니다.

---

**Step 4. 검토 자동 라우팅** *(자동)*

HIGH 위험 + 비표준계약이므로 CAS가 자동으로 검토 요청을 발송합니다.

```
검토 순서: 계약팀 박과장 → 법무팀 이팀장 → 본부장 최이사
계약금액 15억 → 재무팀 병렬 검토 추가
현재 상태: 계약팀 검토 중 (대기 중 1단계)
```

---

**Step 5. 과거 계약 참고** *(자동 검색)*

"A사와 과거에 CR 조항을 어떻게 처리했나요?" 라고 입력하면  
Search Agent가 과거 계약 이력에서 관련 내용을 찾아 답변합니다.

```
📚 검색 결과

2024년 A사 유지보수 계약(v3)에서 CR 처리 조항:
"범위 변경 시 양 당사자 서면 합의 후 별도 견적으로 처리한다."
→ 이 문구를 현재 계약서에 참고하시겠습니까?
```

---

**결과**: 법무팀 요청 없이도 위험 조항을 파악하고, 검토 라우팅이 자동으로 시작됩니다.  
담당자는 협상에 집중할 수 있습니다.

## 7. 차별점

### CAS만의 3가지 차별점

**① MZC 사내 기준 내재화 — "우리 회사 기준으로 분석"**

일반 AI 법률 도구는 보편적 법률 기준으로 분석하기 때문에,  
MZC 표준 계약 조항을 "위험"으로 잡는 오탐이 발생합니다.  
CAS는 **MZC가 허용하는 기준을 프롬프트에 내재화**하여  
실제로 문제가 되는 조항만 정확하게 탐지합니다.  
이 기준은 관리자가 언제든지 수정할 수 있습니다.

**② DMS 실제 업무 흐름과 1:1 대응**

CAS의 검토 단계(CM검토중 → 검토 진행 중 → 승인)는  
메가존클라우드 DMS의 실제 계약 관리 단계와 그대로 대응합니다.  
새로운 시스템을 배우는 것이 아니라 기존 업무 방식을 그대로 유지하면서  
AI 지원을 받는 구조입니다.

**③ 버전 비교 + 히스토리 검색 — "계약 지식의 자산화"**

계약서를 버전별로 관리하고 변경 조항을 자동으로 비교합니다.  
누적된 계약 이력은 자연어 검색으로 즉시 활용 가능하여,  
조직의 계약 노하우가 개인 PC가 아닌 시스템에 축적됩니다.

### 기존 방식과의 비교


| 항목       | 현재 방식         | CAS              |
| -------- | ------------- | ---------------- |
| 리스크 탐지   | 담당자 개인 역량 의존  | MZC 기준 AI 자동 탐지  |
| 검토 요청    | 이메일/메신저 수동 발송 | 리스크 레벨 기반 자동 라우팅 |
| 검토 현황 파악 | 담당자에게 직접 문의   | 대시보드에서 실시간 확인    |
| 버전 관리    | 파일명 수기 관리     | 자동 버전 채번 + 변경 비교 |
| 과거 계약 참조 | 파일 탐색기 수동 검색  | 자연어 검색 즉시 답변     |
| 계약 체결 속도 | 평균 수일         | 당일 목표            |

## 8. 향후 확장 계획

### 단기 (3개월) — DMS 직접 연동

현재 CAS는 독립 시스템으로 동작하지만,  
메가존클라우드 DMS와 API로 연동하면 계약서 업로드 없이  
DMS에서 계약 단계가 시작되는 순간 자동으로 CAS 분석이 시작됩니다.

```
DMS "계약검토 요청" 버튼 클릭
    → CAS 자동 실행 (업로드 불필요)
    → 분석 완료 시 DMS 상태 자동 업데이트
```

### 중기 (6개월) — 학습하는 AI

검토자가 AI 판단에 피드백을 남기면 ("이건 우리 표준이라 위험 아님"),  
그 피드백이 자동으로 다음 분석에 반영됩니다.  
사용할수록 메가존클라우드에 맞게 정확해지는 AI가 됩니다.

### 장기 (1년) — 전사 계약 인텔리전스

- **고객사별 리스크 패턴 분석**: "A사는 배상 조항에서 항상 공격적이다"
- **계약 협상 추천**: 과거 협상 이력 기반 최적 조항 자동 제안
- **QIS 연동**: 계약 승인 완료 시 구매품의 자동 생성
- **계약 만료 알림**: 자동갱신 기한, NDA 만료일 사전 알림
